Al-Awadi's Bullet

About

Al-Awadi's Bullet is a free and open source aim trainer that helps you improve your aim in both 2D and 3D games. Built with the Godot game engine.

Features multiple training modes:

  • Static targets for accuracy training
  • Moving targets for tracking practice

Fully customizable crosshair, sensitivity, and visual settings.

Features

  • Built with Godot
  • Multiple training modes
  • Customizable settings
  • Free and open source

Get Started

  1. Download the latest release
  2. Install on your computer
  3. Start training!
