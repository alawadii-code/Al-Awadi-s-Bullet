## About

**Al-Awadi's Bullet** is a free and open-source aim trainer designed to help improve your aiming skills for both 2D and 3D games. Train your accuracy, reflexes, and tracking with a variety of modes and customizable settings.

---

## Features

- **Static targets** — Precision and accuracy practice
- **Moving targets** — Tracking and prediction training
- **Multiple modes** — Gridshot, Reflex, Moving Targets, and more
- **3D & 2D support** — Train in both perspectives
- **Customizable crosshair** — Adjust to your preference
- **Sensitivity presets** — Pre-configured for popular games
- **Export/Import settings** — Carry your config anywhere

### Modes

| Type | Modes |
|------|-------|
| **3D** | Head Level, Multiple Basic Targets, Multiple Medium Targets |
| **2D** | Gridshot, Reflex, Moving Targets |

## Getting Started

### Download

Grab the latest release from the [Releases](https://github.com/YOUR_USERNAME/Al-Awadi-s-Bullet/releases) page, install, and start training.

### Build from source

1. Clone the repo:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Al-Awadi-s-Bullet.git
   ```
2. Open the project in **Godot 4.6+**.
3. Run the project (F5).
